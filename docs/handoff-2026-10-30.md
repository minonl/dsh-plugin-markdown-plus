## 已知坑（都踩过）

1. **客户端半侧必须是 Cordis 插件**：default export 上要有 `name` + `apply`，否则浏览器报 `invalid plugin, expect function or object with an "apply" method`（宿主取 `exports.default ?? exports`）
2. **同版本 `dsh plugin add` 不会重装**：pnpm 输出 `resolution step is skipped`，必须 `remove` 后再 `add`；校验方式 `grep -c 'apply:' node_modules/<pkg>/dist/client.js` + `dist/build-id.txt`
3. **`scrollIntoView` 会滚整页**：scroll spy 里不能用，改 `list.scrollTop`
4. **作用域**：只认 `[data-sidebar-right-tab]`；`<main>` 回退仅给 dev harness/单测
5. **进程纪律**：不全局 `pkill` 浏览器；只 kill 自己启动的 PID
6. **CI 环境**：真实 DSH e2e 需要 `pnpm`（dsh 委派包操作）+ `@deepseek-ai/dsh` 全局安装
